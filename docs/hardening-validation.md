# 可靠性、安全与混合检索修复验收

本地开发工作区后续修复，日期 2026-10-02。这些修复随后纳入 v0.2.0；[首版验收](validation.md)中的 GitHub CI 与源码指纹仍对应原发布版本。本轮保留已有未提交工作，没有操作个人知识正文。

## 已落实

| 问题 | 当前行为与验证 |
| --- | --- |
| HTML 只依赖 iframe 属性 | 响应头 CSP sandbox 与 iframe sandbox 同时限制来源；预览改用 URL，JSON 分支也设置 CSP。浏览器主动添加 allow-same-origin、移除文档内 CSP 后，父页面、存储与 API 访问仍被阻止。 |
| Git 失败使保存回滚 | 业务提交后尽力备份；hook、index.lock、超时与输出上限故障只返回备份警告。锁文件保留，不覆盖其他 Git 进程持有的暂存锁。 |
| 引用改写覆盖外部编辑 | 首次读取捕获版本，所有引用文件在写入前检查，并在临时文件同步后、发布前再次核对。改名、合并和 fsync 期间注入外部编辑的测试保留新正文并报告冲突。 |
| watcher 抑制丢失编辑 | 抑制期间保留并延后事件，按已索引哈希过滤应用回声；失败重新排队。真实外部编辑发生在抑制窗口内仍进入索引。 |
| 流失败覆盖已验证回答 | 原始流保存不能覆盖已保存的引用校验结果；未验证的中断正文移除无效引用编号。 |
| 仅内存恢复 | 唯一临时文件、文件／目录同步、SQLite FULL 同步、持久化日志与事务提交标记。SIGKILL 测试覆盖改名、清空、恢复与清理回收站，包含二进制原件；重复恢复安全，外部编辑冲突保留日志并阻止写入。 |
| 检索缺少语义能力 | 独立嵌入／重排设置，文字＋向量 RRF 融合、一跳关系扩展、候选精排。中文分词、名称索引与有界图谱查询保留；向量失效由触发器处理，网络返回后再次检查原文哈希。 |
| 界面文案和错误契约 | use-intl 中英文目录、Cookie 记忆与即时切换；保留未保存表单与后台草稿。错误码独立于中文说明，前端冲突判断使用错误码。 |
| 状态与组件耦合 | 按知识／会话／审阅／设置范围刷新；导入 28 个独立 state 收拢到 reducer，类型单独管理；聊天消息与回答归档拆出，主工作区约 983 行、16 个 state；导入选择与审阅、词条删除／合并、审阅卡片与导航行分别拆成模块。 |
| 重复与成本 | 删除无路由的 Git 历史包装；统一 token 估算；草稿单份保存；分段检查点增量写并兼容旧格式；文件 200 MB、解析正文 250,000 估算 token 上限；整页改写统计新增字符；三处 SSE 复用共享实现。 |

## 模型选择与真实连接

按[硅基流动价格页](https://siliconflow.cn/pricing)在查询时标示的免费模型，选择 `BAAI/bge-m3` 与 `BAAI/bge-reranker-v2-m3`。bge-m3 的[官方模型说明](https://huggingface.co/BAAI/bge-m3)列出多语言、1024 维和 8192 token 输入；该选择适合本项目的中英文知识库，不代表在所有资料上绝对最优。

连接探针使用本地设置中的凭据，公开响应仅返回 `hasApiKey`。真实连接仅发送两条固定合成文本和一条查询：嵌入返回 1024 维，重排将相关文本排在首位，单次合计约 631 ms。没有上传个人正文，文档不保存密钥或完整上游日志。该探针验证账号与协议可用，不能证明真实知识库回答质量；价格、免费额度与账号权限可能变化。

## 检查与边界

环境：macOS / arm64、Node 26.3.1、pnpm 11.7.0、Next.js 16.3.6、Chrome。单元与浏览器验收使用临时知识库和模拟服务。最终回归包含临时文件同步期间的外部编辑、检索配置变更取消旧请求，以及组件拆分后的完整流程。

- `pnpm lint`、`pnpm typecheck` 与 `pnpm build --webpack` 通过；`pnpm test` 的 48 个文件、765 个测试全部通过；`WEAVE_E2E_BROWSER_CHANNEL=chrome pnpm test:e2e` 的 18 项流程全部通过，包括中英文与独立检索配置、无障碍、窄屏、取消、归档和两类 HTML 隔离。
- 构建采用 `pnpm build --webpack`，因当前受限执行环境中 Turbopack 的端口创建曾返回 EPERM。构建保留既有 unpdf import.meta 警告，没有将其列为新失败。
- UI 机械检测无发现；桌面与窄屏截图检查未发现横向溢出。自动无障碍检查不等于完整认证。
- `git diff --check` 通过；源码、测试与文档中的密钥模式扫描无发现，用于真实连接探针的临时凭据文件已删除。
- 性能数据与复测命令见[性能记录](performance-audit.md)。向量本地扫描包含模拟查询向量与候选读取，不包含真实网络或重排时间；不能据此声称回答质量提高或所有查询提速。

仍采用单进程、本机单用户边界，没有账号认证。其余大型工作区未全面重构；没有引入聊天模型查询改写或近似向量索引。恢复拒绝覆盖检测到的外部编辑，但文件系统与 SQLite 并非硬件统一事务，不能保证所有设备故障与断电点。真正的检索质量需要标注问题和实际知识库验证。
