# 织识：从资料到可维护的知识

织识（weave）是开源、本地运行、单用户的知识管理工具。原始资料经过模型分析和人工审阅，成为可以外部编辑的 Markdown 词条；双链、检索问答、答案归档和体检用于持续维护这些内容。使用者自行选择模型服务，文件和应用状态保存在本机。

## 核心逻辑与产品价值

围绕一个主题学习时，资料会持续增加，同一概念会出现在多份文件中。织识保留原件，将内容组织为概念词条，允许用户修改草稿和确认写入；问答时返回关联证据，有用的结论可以继续归档为词条。新增资料和后续整理都围绕同一知识库进行。

## 使用取舍与尚未完善的部分

- **模型与审阅成本**：导入分析和问答需要配置模型，网络调用可能产生费用与等待；模型整理结果需要用户判断。没有模型时仍可浏览、编辑和文字搜索。
- **本地数据管理**：使用者掌握文件与服务选择，也需要负责完整备份。保存在 SQLite 的服务密钥未加密；云端模型、嵌入、重排或解析服务会收到任务所需内容。
- **平台与协作**：桌面包仅提供 Apple Silicon macOS，未公证；源码有 macOS／Ubuntu CI，Windows 未验收。没有账号认证、多人协作、设备同步或公网部署支持。
- **规模与解析**：精确向量扫描随分段数量和维度增加成本，长问题也会增加本地计算。OCR 与 PPTX 需要另行配置 Docling，安装包未捆绑 Python 或 OCR 模型。
- **质量覆盖**：真实评测范围有限，长文、多跳、自然缺证据、不同领域和商业产品比较尚未验证。部分工作区与流水线仍较大，增加功能时需要保持现有职责边界与回归覆盖。
