# 织识：从资料到可维护的知识

织识（weave）是本地运行的开源个人知识管理工具。它将资料编译为 Markdown 词条，经人工审阅写入，利用双链和全文索引组织知识，再围绕问题提供带引用的回答。使用者自行配置模型服务，文件和应用状态保存在自己的电脑上。

## 解决的问题

日常学习容易积累大量文件，但资料之间的概念联系、重复说明与新旧差异难以维护。一次问答也经常停留在会话中，没有回到知识库。

织识将这些步骤连接起来：保留原件，生成可修改的词条草稿，让用户确认变更，再把问答结论归档。模型参与分析与表达；内容证据、最终写入和维护操作都有明确边界。

## 三个典型场景

| 场景 | 操作与结果 |
| --- | --- |
| 学习一个新主题 | 导入笔记、文章或文档，审阅概念词条，用图谱查看关联，再通过问题检索相关内容 |
| 持续补充资料 | 导入新文档，查看已有词条的补充建议、引用与潜在矛盾，编辑草稿后写入 |
| 整理已有知识 | 搜索、修改或合并词条，体检死链与语义问题；把聊天回答归档，删除内容可从回收站恢复 |

## 技术结构与取舍

**持久化分工。** Markdown 是知识内容的真源，便于外部编辑和长期保存。SQLite 承担 FTS5 索引，并保存无法从文件恢复的会话、任务、来源和审阅状态；Git 记录知识文件变化。完整备份覆盖三者，不能把数据库整体当作缓存。

**检索与上下文预算。** 使用 SQLite FTS5 trigram 和短词兜底，根据问题选取相关词条片段，再组合历史、摘要与证据。当前不依赖独立向量数据库；长问题与大库的成本通过合成基准单独记录。

**可恢复的后台任务。** 单进程串行队列保存任务状态、分段结果和人工草稿，支持取消、检查点与重启恢复。写入检查内容哈希，避免覆盖审阅期间的外部改动；可捕获失败尝试恢复文件和 Git 暂存，并明确报告恢复不完整。

**模型兼容与信任边界。** 服务元数据优先，能力未知时保留默认；协议适配、结构化输出、校验和错误脱敏集中处理。资料和摘要作为不可信内容注入，引用由后端检查；个性化仅调整表达，不覆盖证据。

**本机交付。** Next.js 承载页面和 Node API，结合 TypeScript、React 与 Drizzle。标准启动只监听本机回环地址，校验 API Host 和 Origin；不包含认证体系，不面向公网或多人共享。

完整架构见 [architecture.md](architecture.md)，维护限制见 [release-audit.md](release-audit.md)。

## 可核验的工程证据

首版源码在干净克隆和隔离知识库中完成安装、生产构建、严格类型与 lint 检查；44 个文件的 728 项测试和 16 项浏览器测试通过。故障注入覆盖回滚再次失败与 Git 暂存恢复；浏览器检查覆盖完整业务流程、设置、搜索取消、窄屏、键盘和 HTML 预览隔离。

[验收记录](validation.md)保留环境、范围与源码指纹；[性能基准](performance-audit.md)提供 300 与 1,000 词条的原始 JSON 和复测方法；[GitHub Actions](https://github.com/qinyuhao84-ship-it/weave/actions)展示后续自动回归；[首轮修复后的 macOS / Linux 回归与密钥扫描](https://github.com/qinyuhao84-ship-it/weave/actions/runs/36874861409)已通过。模拟测试证明应用流程，不能证明真实模型事实判断或通用回答质量。
