# 织识：面向专题学习与研究的个人知识工具

织识（weave）帮助学生、教师和独立研究者，把围绕一个主题的资料整理成可以持续补充和复用的知识库。模型协助提炼概念词条、连接相关内容，并提出更新建议；使用者核对来源、修改草稿后再确认写入。之后可以在知识库中提问、查看引用、生成交互图解，并把有用的答案归档。

织识开源、本地运行，主要面向单人使用。知识词条以可外部阅读和编辑的 Markdown 文件保存；会话、原始资料和审阅记录等应用状态保存在 SQLite。使用者选择模型服务，资料存放在本机；调用远程模型时，会发送完成当前任务所需的内容。

## 产品定位：把专题资料整理成可持续维护的知识

一个主题的资料会逐渐增加，同一概念可能出现在多份文件中，新的证据也可能改变已有结论。织识将导入、知识整理、人工审阅、引用问答和后续维护连成一条工作流程，让一次次学习可以建立在此前整理的知识上。

织识适合手头已有一组资料，并准备持续研究同一主题的人。例如，学生可以整理课程资料与论文，教师可以整理备课材料与学科内容，独立研究者可以围绕一个问题累积来源与观点。它强调可检查、可编辑、能继续更新的专题知识成果。

## 产品特点

- **知识可以逐步积累**：新资料会生成词条草稿和已有内容更新建议；用户确认后写入 Markdown 知识库，问答结论也可以归档为词条。
- **整理结果可以核对**：导入草稿展示原文来源，回答提供可查看的引用；发现矛盾、死链或重复内容时，用户可以检查建议并选择处理方式。
- **内容可以用不同方式理解**：除文字回答外，可以生成带图形与交互的 HTML 阅读页面，帮助呈现过程、关系和观点比较。
- **日常操作集中在桌面应用**：桌面包内置运行环境，浏览、编辑和搜索无需安装开发工具或使用终端。模型服务和密钥仍需自行配置。

交互图解、资料审阅和答案归档都有相应实现；现有评测主要验证特定检索语料、问答题目和工程流程，尚未证明用户普遍更容易理解、完成任务更快或留存更高。功能证据与限制见下表及后续章节。

## 使用取舍

模型生成内容需要用户审核；模型调用可能产生费用与等待。知识文件留在本机，但调用云端模型、嵌入、重排或解析服务会将对应资料内容发送给所选服务。首次使用需要配置模型服务，使用者也需要负责完整备份。

资料整理、证据问答和交互图解围绕同一知识库工作。导入后可以检查词条和引用；提问时可以回到关联证据；新资料、问答结果与知识库体检又能继续用于更新和维护。

## 使用取舍与尚未完善的部分

- **模型与审阅成本**：导入分析和问答需要配置模型，网络调用可能产生费用与等待；模型整理结果需要用户判断。没有模型时仍可浏览、编辑和文字搜索。
- **本地数据管理**：使用者掌握文件与服务选择，也需要负责完整备份。保存在 SQLite 的服务密钥未加密；云端模型、嵌入、重排或解析服务会收到任务所需内容。
- **平台与协作**：桌面包仅提供 Apple Silicon macOS，未公证；源码有 macOS／Ubuntu CI，Windows 未验收。没有账号认证、多人协作、设备同步或公网部署支持。
- **规模与解析**：精确向量扫描随分段数量和维度增加成本，长问题也会增加本地计算。OCR 与 PPTX 需要另行配置 Docling，安装包未捆绑 Python 或 OCR 模型。
- **质量覆盖**：真实评测范围有限，长文、多跳、自然缺证据、不同领域和商业产品比较尚未验证。部分工作区与流水线仍较大，增加功能时需要保持现有职责边界与回归覆盖。
