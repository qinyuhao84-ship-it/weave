# 织识：从资料到可维护的知识

织识（weave）是本地运行的开源个人知识管理工具。它将资料编译为 Markdown 词条，经人工审阅写入，利用双链和全文索引组织知识，再围绕问题提供带引用的回答。使用者自行配置模型服务，文件和应用状态保存在自己的电脑上。

## 解决的问题

日常学习容易积累大量文件，但资料之间的概念联系、重复说明与新旧差异难以维护。一次问答也经常停留在会话中，没有回到知识库。

织识将这些步骤连接起来：保留原件，生成可修改的词条草稿，让用户确认变更，再把问答结论归档。模型参与分析与表达；内容证据、最终写入和维护操作都有明确边界。

## 三个典型场景

| 场景 | 操作与结果 |
| --- | --- |
| 学习一个新主题 | 导入笔记、文章或文档，审阅概念词条，用图谱查看关联，再通过问题检索相关内容 |
| 持续补充资料 | 导入新文档，查看已有词条的补充建议、引用与潜在矛盾，编辑草稿后写入 |
| 整理已有知识 | 搜索、修改或合并词条，体检死链与语义问题；把聊天回答归档，删除内容可从回收站恢复 |

已发布 [macOS Apple Silicon 桌面安装包](https://github.com/qinyuhao84-ship-it/weave/releases/tag/v0.2.0)，内置运行时与本地 Git，日常使用无需 Node、pnpm 或终端。使用与平台限制见 [桌面说明](desktop.md)。功能与真实界面截图见 [README](../README.md)。截图来自隔离的合成演示，不展示个人数据，也不作为模型质量评测。

## 技术结构与取舍

**持久化分工。** Markdown 是知识内容的真源，便于外部编辑和长期保存。SQLite 承担 FTS5 索引，并保存无法从文件恢复的会话、任务、来源和审阅状态；Git 记录知识文件变化。完整备份覆盖三者，不能把数据库整体当作缓存。

**检索与上下文预算。** 使用 SQLite FTS5 trigram 和短词兜底；可选混合检索通过独立嵌入与重排服务，融合文字、向量和一跳关系候选，根据问题选取片段，再组合历史、摘要与证据。当前不依赖独立向量数据库；真实中文检索质量与本地延迟已有冻结评测，长问题与大库的成本另由合成基准记录。

**可恢复的后台任务。** 单进程串行队列保存任务状态、分段结果和人工草稿，支持取消、检查点与重启恢复。写入检查内容哈希，避免覆盖审阅期间的外部改动；可捕获失败尝试恢复文件和 Git 暂存，并明确报告恢复不完整。

**模型兼容与信任边界。** 服务元数据优先，能力未知时保留默认；协议适配、结构化输出、校验和错误脱敏集中处理。资料和摘要作为不可信内容注入，引用由后端检查；个性化仅调整表达，不覆盖证据。

**本机交付。** 桌面版以原生 Cocoa / WKWebView 窗口运行，自动启动内置 Next.js standalone 服务并在退出时关闭；源码版可通过浏览器使用。Next.js 承载页面和 Node API，结合 TypeScript、React 与 Drizzle。两种方式都只监听本机回环地址，校验 API Host 和 Origin；不包含认证体系，不面向公网或多人共享。

完整架构见 [architecture.md](architecture.md)，维护限制见 [release-audit.md](release-audit.md)。

## 可核验的工程证据

v0.2.0 已通过 macOS / Ubuntu 的 lint、生产构建、严格类型检查、49 个文件的 777 项测试、18 项浏览器端到端及完整历史凭据扫描。[最新完整回归](https://github.com/qinyuhao84-ship-it/weave/actions/runs/36960819018)。实际 DMG 安装应用另通过原生窗口搜索编辑、系统文件选择/保存、导入审阅、引用与 HTML 交互、退出重启及持久化验收，见 [桌面验收](desktop-validation.md)。安装链路使用隔离资料和模拟模型，不作为真实回答质量证据。

真实评测使用 10,080 篇共享资料、200 道最终检索留出题以及 80+20 个问答场景。最终 `Recall@10` 为 98.68%、`nDCG@10` 为 0.8536，比开发预选最强基线高 4.19 个百分点；有答案正确率 97.5%、引用支持及受控拒答均为 100%。这些结论仅覆盖受限语料和本次逐题复核范围，不代表市场产品平均水平。[指标解释与限制](evaluation/2026-10-02/metrics.md)。

[首版历史验收](validation.md)保留当时环境与源码指纹；[性能基准](performance-audit.md)提供 300 与 1,000 词条的合成基准；[GitHub Actions](https://github.com/qinyuhao84-ship-it/weave/actions)展示持续回归。
