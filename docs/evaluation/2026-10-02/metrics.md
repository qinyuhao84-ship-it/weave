# 指标定义与结果解读

数据、实现和参数均已冻结；本页解释 2026-10-02 最终第三轮结果，不重新运行或调参已曝光的留出题。检索由公开人工相关性标注自动计分，问答对照答案与实际证据逐题复核。

## 样本、模型与比较条件

共享语料包含 10,000 段 MIRACL 中文资料及 80 篇 CMRC2018 资料，保留正例、已标注负例与干扰资料。开发题 200 道，最终新留出题 200 道；新留出排除历史重复问题与正例文章。问答另有 80 道有答案题和 20 道受控移除证据的无答案场景。来源版本、划分、许可证及内容哈希见 [数据清单](round-3/dataset/manifest.json)。这是受限语料，不是全量 MIRACL 排行榜。

检索统一使用 `BAAI/bge-m3` / `BAAI/bge-reranker-v2-m3`、Top-K=10；检索比较上下文预算 24,000 字符，证据和问答套件实际上下文预算 8,192 字符、模型窗口 32,768。问答统一使用 OpenCode Go `deepseek-v4-flash`。环境为 macOS 15.7.4、Apple M2、24 GB 内存、arm64、Node 26.3.1。

开发集先比较原实现、中文分词 BM25、纯向量、标准 RRF + 重排；纯向量的开发 `nDCG@10` 最高（0.84809），因而在开启留出前预选为最强基线。BM25 与 RRF 未被预选，不补跑最终留出挑选有利对手。[开发比较](round-3/dev-comparison/report.md) · [冻结回执](round-3/frozen.json)。

## 检索指标

每题先按资料 ID 去重，保留首次出现的位置，再取前 K 条；相关性标注大于 0 为正例。以下结果为逐题计算后取平均，失败题不丢弃。`@5` / `@10` 指前 5 / 10 条。

| 指标 | 最终结果 | 含义与计算口径 |
| --- | --- | --- |
| `Recall@5` / `Recall@10` | 88.94% / 98.68% | 前 K 条中的已标注正例数 ÷ 该题全部已标注正例数；衡量找回了多少相关资料 |
| `Hit@5` / `Hit@10` | 98.00% / 99.50% | 至少找到一个已标注正例的问题占比；不等于全部相关资料都找到 |
| `MRR@10` | 0.8421 | 第一个正例排名的倒数；前 10 条无正例记 0，越接近 1 越好 |
| `nDCG@10` | 0.8536 | 用相关性增益和排名折扣计算 DCG，再除以理想排序 DCG；越接近 1 越好 |
| `Precision@5` / `Precision@10` | 36.00% / 21.20% | 已标注正例数 ÷ 固定 K；未标注和缺少的位置按 0 计 |
| `已标注结果准确率@10` | 26.13% | 已标注正例数 ÷ 返回结果中有标注的条数；排除未标注结果，仅反映已判断部分 |
| `标注覆盖率@10` | 80.95% | 前 10 条实际返回结果中有正例或负例标注的比例；约 19.05% 没有相关性判断 |
| `实际证据覆盖率@10` | 80/80，100% | CMRC 答案原文是否出现在真正送入模型的片段中；上下文截断后仍必须包含证据 |

nDCG 使用增益 `2^相关性 - 1`，第 r 位折扣为 `log2(r+1)`；MRR 与 nDCG 是 0–1 得分。MIRACL 没有答案跨度，其相关词条召回不能当作证据覆盖；最后一行只来自 CMRC 证据套件。

**不完整标注限制：`Precision@10` 的 21.20% 不能解释为“只有 21.20% 的结果真实相关”，也不能用 98.68% 的 Recall 当作准确率。** 未标注结果可能相关；已标注结果准确率的分母也有选择偏差。三项一起报告，nDCG 对未标注按 0 计同样受此限制。各平均比率不能直接相除还原另一项。[指标实现](../../../scripts/eval/metrics.ts) · [证据汇总](round-3/evidence/summary.json)。

## 优化幅度与工程门槛

| 指标 | 原实现 | 开发预选最强基线：纯向量 | 最终方案 |
| --- | --- | --- | --- |
| `Recall@10` | 98.50% | 98.25% | 98.68% |
| `nDCG@10` | 0.82501 | 0.81163 | 0.85358 |
| `MRR@10` | 0.80724 | 0.78531 | 0.84213 |
| 本地检索 P95 | 111.55 ms | 89.63 ms | 122.67 ms |

最终 nDCG 相对预选基线提高 **4.19 个百分点**，相对原实现提高 **2.86 个百分点**。配对 bootstrap 按同一批 200 题重采样 5,000 次，固定种子 20261002；相对预选基线提升的 95% 区间为 **[1.85, 6.63] 个百分点**。该区间描述本样本的排序改善，不证明跨领域或商业产品优势。

| 本阶段门槛 | 最终结果 |
| --- | --- |
| `Recall@10` ≥85% | 98.68%，通过 |
| `nDCG@10` ≥0.70，且高于预选基线 ≥3 个百分点 | 0.8536 / +4.19 个百分点，通过 |
| 排序提升 95% 区间下界 >0；召回下降不超过 2 个百分点 | 下界 +1.85；召回高于基线 0.42 个百分点，通过 |
| 本地 P95 相对原实现恶化不超过 20% | +9.97%，通过 |
| 有答案正确率 ≥85%；引用支持 ≥95%；受控拒答 ≥90% | 97.5% / 100% / 100%，通过 |

保留的优化为精确 BGE 组合去掉重排输入中的重复标题，并校准低置信差的排序；没有增加网络调用或改生产索引。前两轮未达到全部门槛，失败报告继续公开；每轮失败后建立新留出，最终方案冻结后只运行一次本轮留出。达到门槛后停止调参。[三轮记录](README.md) · [最终逐题失败样例](round-3/test-comparison/failures.json)。

## 延迟、缓存与失败

中位数是排序后中间值（偶数取中间两值平均）；P95 为第 `ceil(0.95 × 样本量)` 个值。所有单位为毫秒，数值不能简单相加得到端到端 P95。

| 阶段 | 样本量 | 中位数 / P95 | 口径 |
| --- | --- | --- | --- |
| 原实现本地检索 | 200 | 86.45 / 111.55 | 排除嵌入、重排的网络等待 |
| 最终方案本地检索 | 200 | 87.85 / 122.67 | 同语料同环境，含本地召回与排序工作 |
| 嵌入真实网络请求 | 200 | 184.09 / 408.24 | 原实现首次测量；最终方案复用这批真实向量，实际新请求样本量为 0，延迟为空值 |
| 原实现重排真实请求 | 200 | 482.39 / 630.26 | 实际网络等待，含同题重试 |
| 最终方案重排真实请求 | 200 | 476.99 / 596.57 | 实际网络等待，含同题重试 |
| 最终问答端到端首字 | 100 | 2,018 / 3,150 | 从发起评测到首段正文，包含检索准备 |
| 最终问答端到端完成 | 100 | 2,071 / 3,216 | 从发起评测到完成 |
| 模型请求后首字 / 完成 | 各 100 | 1,705 / 2,748；1,760.5 / 2,775 | 从问答模型请求发出起计，不含此前检索 |

原实现、最终方案与纯向量在最终检索留出上均为失败 0/200、降级 0/200；最终问答为失败 0/100、降级 0/100。失败率按请求失败题数计算，降级率按因服务不可用而回退的题数计算；本轮零失败不能保证未来服务可用性。

原实现的 400 次检索网络请求包含 200 次嵌入和 200 次重排；最终方案有 200 次真实重排请求及 200 次嵌入缓存命中。纯向量使用缓存向量。因此总墙钟耗时不能拿来宣称端到端速度提升，零网络样本也不写成 0 ms。[检索完整汇总](round-3/test/summary.json) · [问答阶段耗时](round-3/answers/answer-status.json)。

## 问答评分与适用范围

有答案正确率为 78/80（97.5%）：核对原问题、标准答案、实际原文，以及回答的额外断言。两道题将学士问成博士、制作公司问成发行方，模型保留了原文事实边界，但按直接答复的保守口径不计答对，缺陷原样披露。

引用支持为 80/80（100%）：逐题核查有答案回答中的引用是否在实际证据中支持结论；合法引用编号本身不构成通过理由。这是题级通过率，不是把所有引用条目混成一个分母。受控拒答为 20/20（100%），单独统计，不与有答案题混合。

问答已逐题复核，但未进行独立人工盲审。小样本 100% 不等于真实使用零错误。受控无答案由移除资料并核查残留答案建立，不能代表自然缺证据、多轮、多跳、长文或 OCR；评测也不核验历史原文是否仍符合当前现实。[复核记录](round-3/answers/reviews.jsonl) · [标注缺陷](round-3/answers/label-audit.json) · [最终状态](status.json)。

本阶段所有指标是工程目标，结论为超过本次开发预选的成熟检索基线；没有实测商业知识库产品，不能宣称超过市场产品平均水平。完整资料、逐题输出和冻结源码可从 [Release 附件](https://github.com/qinyuhao84-ship-it/weave/releases/tag/v0.2.0) 下载；[复现命令](../../retrieval-evaluation.md) 无需改日常配置。普通 CI 只执行离线回归，不消费真实模型额度。
