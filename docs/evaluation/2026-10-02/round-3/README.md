# 第三轮冻结评测

本轮检索、真实问答及最终工程检查均已达到工程门槛，停止优化。数据为 10,080 篇公开资料、200 道开发题、200 道新的留出题；另有 80 道有答案及 20 道受控缺证据场景。排除了历史 600 道开发/测试问题的重复题以及历史正例文章用于新留出；开发问题保留，问答标题排除历史 200 篇。首次使用的新测试题来自 MIRACL 未使用的 train/dev 池，不能直接横向比较不同轮次总分。

| 方法 | 开发 `nDCG@10` | 留出 `nDCG@10` | 留出 `Recall@10` | 留出本地 P95 |
| --- | --- | --- | --- | --- |
| 原实现 | 0.84241 | 0.82501 | 98.50% | 111.55 ms |
| 中文分词 BM25 | 0.46642 | 未被预选 | — | — |
| 纯向量（开发最强基线） | 0.84809 | 0.81163 | 98.25% | 89.63 ms |
| 标准 RRF + 重排 | 0.84069 | 未被预选 | — | — |
| 最终方案 | 0.88233 | 0.85358 | 98.68% | 122.67 ms |

最终方案相对预选基线 nDCG 提升 4.19496 个百分点，配对 bootstrap 95% 区间 [1.85065, 6.62941] 个百分点；相对原实现提升 2.85717 个百分点。原实现与最终方案召回、排序、服务及本地延迟使用同语料同环境比较。本地 P95 增加约 9.97%，低于 20% 上限。失败和降级均为 0。各类网络等待、缓存样本量及标注不完整限制见 [汇总](test/summary.json)；网络延迟不与缓存耗时混用。

保留的改动：对精确 BGE-M3 / BGE-reranker-v2-M3 组合，重排输入去掉重复词条标题；低置信差（前两名差 <0.2）且分数属于 [0,1] 时，按 `logit(重排分数) + 30 × 余弦相似度` 校准排序。其他模型输入与顺序保持原行为。参数只依据开发集选取，冻结后运行一次新留出测试；不会为测试失败样例再调参。无需增加网络调用或生产索引。

检索门槛全部通过，停止检索优化。该受限公开语料试验证明超过预选成熟算法基线，不能代表行业平均、全量 MIRACL 或个人长文/图谱资料的完整表现。已有失败轮次继续公开。

## 证据片段

80 道 CMRC 有答案题全部召回相关词条，并在真正送入模型的片段中覆盖答案原文：原实现、最终方案及纯向量的证据 `Recall@10` 均为 100%。最终方案 `nDCG@10` 为 1.0，失败和降级均为 0。上下文预算 8,192 字符，检索问题与问答复核保持一致；这项检查不代替模型答案与引用核查。[完整证据结果](evidence/summary.json)。

## 真实问答复核

最终方案另运行全新的 100 个场景，对照标准答案、实际送入的原文与额外断言逐题复核。按原问句直接作答的保守口径，有答案正确率 78/80（97.5%），引用支持 80/80（100%），受控缺证据正确拒答 20/20（100%），三项门槛均通过。

两道题不记为直接答对：原问句将原文的语言学学士写为博士，以及将动画制作公司问成发行方。模型都正确保留了事实边界，没有伪造博士学位或把制作方当成发行方；数据清单与标准答案保持原样，问题瑕疵在 [标注核查](answers/label-audit.json) 和 [逐题复核](answers/reviews.jsonl) 中披露。姓名错写等其余情况也逐题说明。引用核查包含实际上下文的后段，不只核查引用编号或展示摘要。

- 最终一轮问答首字中位数 / P95：2,018 / 3,150 ms；完成：2,071 / 3,216 ms。
- 模型请求后首字中位数 / P95：1,705 / 2,748 ms；完成：1,760.5 / 2,775 ms。
- 两轮合计 200 次调用（含失败尝试的累计口径），高峰价格计价 $0.209781，未跨窗口续跑，未使用余额备用方式或付费直连；最终一轮失败、降级均为 0。临时评测凭据已清理，累计账本保留。

## 工程验证与复现

`pnpm lint`、`pnpm build`、`pnpm typecheck`、`pnpm test` 全部通过；49 个测试文件、777 项测试通过。相关检索/模型恢复端到端 2 项通过（7.9 秒）。普通 CI 只运行临时知识库的离线回归，不消费真实模型额度。

原 Turbopack 构建受本机 CSS worker 端口权限限制；构建脚本默认使用官方支持的成熟 Webpack，显式选择 Turbopack 的能力保留，最终 `pnpm build` 已成功。构建过程保持独立临时知识库。三轮资料、划分与答案均重新准备，9 个文件的 SHA-256 与原清单一致；没有重跑已曝光留出题。
