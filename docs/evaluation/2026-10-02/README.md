# 真实评测执行记录

本记录使用真实公开资料和人工标注，真实检索模型为硅基流动的 `BAAI/bge-m3` 与 `BAAI/bge-reranker-v2-m3`。所有运行使用隔离知识库，不修改个人资料或日常模型配置。统计只代表本受限语料评测，不能解释为知识库产品行业平均。

[指标定义、样本量、基线与延迟口径](metrics.md)。Recall、Precision 与问答正确率是不同指标；不完整相关性标注和代理复核的限制在说明中单独披露。

首轮留出排序相对预选基线提高 2.01 个百分点，配对 bootstrap 95% 区间为 [0.84, 3.26] 个百分点。召回、排序绝对门槛、置信区间、召回非回退和本地延迟门槛通过，3 个百分点门槛未通过。本地 P95 为原实现 96.11 ms、候选 96.73 ms（+0.65%）。详情见 [留出报告](test-comparison/report.md)、[冻结回执](frozen.json)、[失败样例](test-comparison/failures.json)。

逐题核对标准答案、实际送入模型的原文和引用支持关系，未以自动字符串匹配替代证据复核。例如标准答案中的语法助词、正确的词条别名与省略表达未机械误判；额外地点和亲属关系回到原文核对，长引用同时核查实际上下文，避免只检查 600 字符展示摘要。

## 后续流程

首轮留出题已关闭，不再参与调参。后续继续使用原 200 道开发题，同时排除历史问题规范化哈希和正例文章，从未使用的 MIRACL official train/dev 池建立新 200 道留出题；新题的来源在 ID 中记录。新的 CMRC 场景也排除已有答案及受控缺证据文章标题。新语料与所有基线共同重新运行，禁止跨语料直接比较延迟。

第二轮先比较低置信差的 RRF，再依据开发失败样例校准归一化重排分数。最终冻结 `logit(重排分数) + 40 × 余弦相似度`，仅对精确的 BGE 模型组合、分数处于 [0,1] 且前两名差 <0.3 时启用；其余情况保留原重排顺序。开发 nDCG 为 0.87446，相对本轮最强基线纯向量的 0.84627 提升 2.82 个百分点；冻结后才开启本轮新留出测试。第二轮留出 `nDCG@10` 为 0.83822，纯向量为 0.82500，提升 1.32 个百分点，原实现为 0.83936；`Recall@10` 为 98.475%。未达到 3 个百分点且略低于原实现，分数校准已撤回。冻结、测试和报告在 `round-2/` 中单独保存，所有失败轮次均披露。随后仅在开发集验证去掉重排请求中的重复标题，原 400 道已曝光留出题与其正例文章不再作为新测试题。
