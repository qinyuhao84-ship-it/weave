## 视觉与交互自检

| 维度 | 调整与观察 |
| --- | --- |
| 排版 | 页面标题、区块标题、正文和辅助信息保持明确层级；数字用量紧凑排版；删去所指定的重复解释。 |
| 留白 | 上下文明细、回答和输入区各自有稳定内边距；最近对话占据剩余可用高度，长列表不会挤走底部状态。 |
| 视觉层级 | 问答正文是主体；引用状态使用小标签；上下文用量默认紧凑，展开后显示明细；主要操作位置稳定。 |
| 色彩 | 沿用黑白、暖灰体系；浅深色分别复核。状态色仅用于既有语义，边界和阴影保持克制。 |
| 动效 | 弹层约 160ms 淡入与小幅位移，侧栏过渡约 220ms；检查减少动态效果模式，侧栏过渡为 0s。 |
| 微交互 | 统一悬停、选中和焦点状态；搜索连续输入不丢焦点；键盘选择、关闭及焦点恢复通过；最近对话箭头反映展开状态。 |
| 响应式 | 测试覆盖 320、390、768、796、1024、1366、1920px，以及低高度窗口。检查长标题、长链接、筛选、模型菜单和聊天输入区，无页面横向溢出。 |
| 原创性 | 保留织识标识及已有 AI 状态表达，围绕知识工具的阅读和检索需求完善视觉；圆角和分层采用适合当前产品的尺度。 |

## 验证证据及边界

- `pnpm lint`：通过。
- `pnpm build`：通过；已有 unpdf 的 import.meta 构建警告仍存在。
- `pnpm typecheck`：通过。
- `pnpm test`：49 个测试文件、780 项测试通过。
- `pnpm test:e2e`：25 项通过，包含流程、响应式、国际化兼容、无障碍、下拉搜索及减少动态效果。
- `git diff --check`：通过。
- impeccable 检测脚本：退出码 0；没有将脚本结果换算为设计分数。
- 自动化使用临时知识库、模拟模型和独立测试服务；真实知识库仅做页面观察，不改个人资料。模拟回答用于检查链路与视觉，不代表真实模型回答质量。
- 本批次仅验收界面；后续桌面与发布结果由各自版本记录。

动效采样环境为 Chromium 153.0.8010.12，1366×900，40 条模拟会话；在侧栏收起/展开时采样 3 次，每次 500ms。帧间隔中位数分别为 **33.3 / 33.3 / 16.7ms**，P95 均约 **33.4ms**。这是无头浏览器中的短时 RAF 采样，受运行环境调度影响，不能证明所有真实设备恒定 60fps，也没有作为改动前后的性能提升对比。

## 思考档位依据

服务元数据优先；只有已确认的模型采用补充规则，未知模型保留服务默认。UI 不显示 default/none。三档选中间档；偶数档选靠上的中间档；已明确选择且仍支持的真实档位保留。轻量任务自身的降档约束保持独立。

- [DeepSeek 官方思考模式](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/)：low / high / max，默认 high。
- [Google 官方 OpenAI 兼容接口](https://ai.google.dev/gemini-api/docs/openai)：核对 Gemini 各系列 thinking level 与 reasoning effort 映射。
- OpenAI 官方模型页：[GPT-6 Astra](https://developers.openai.com/api/docs/models/gpt-6-astra)、[GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol)、[GPT-5.4](https://developers.openai.com/api/docs/models/gpt-5.4)、[GPT-5.4 mini](https://developers.openai.com/api/docs/models/gpt-5.4-mini)、[GPT-5.2](https://developers.openai.com/api/docs/models/gpt-5.2)、[GPT-5.1](https://developers.openai.com/api/docs/models/gpt-5.1)、[GPT-5](https://developers.openai.com/api/docs/models/gpt-5)，以及 [推理模型指南](https://developers.openai.com/api/docs/guides/reasoning)。OpenAI 名称补充规则仅用于其官方服务地址，其他提供商以返回的能力信息为准。
- [Ariakit 搜索选择器官方示例](https://ariakit.com/examples/select-combobox)：复用成熟组件处理键盘、焦点与定位。
