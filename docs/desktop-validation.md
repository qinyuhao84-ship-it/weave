## 安装包实测

环境：macOS 15.7.4、Apple M2 / arm64。挂载实际 DMG（只读），从映像复制应用到独立安装路径，设置隔离测试知识库，仅以 `/usr/bin:/bin` 为初始 PATH 启动应用本身。未修改真实知识库、日常模型配置或系统安全设置。

已验证：DMG 校验和有效、应用深度签名完整性通过、22 个依赖链接均在包内、无 `.env` 或数据库分发、Node/SQLite ABI 可用、内置 Git 不依赖 Xcode 或 Homebrew。官方运行时及 Git 仅链接系统库，构建最低版本 13.5。

安装后后台链路实测：空库初始化、Markdown 文件监听索引、编辑落盘、全文搜索、检索模型连接与向量索引、本地模拟问答、后端引用校验及 Git 版本保存均通过。退出信号经过原生应用清理流程，启动器与服务均停止；重新启动后词条修改、模型设置和会话/引用仍存在。安装包链路测试使用本地模拟模型，不作为回答质量证据；真实模型质量另由冻结评测证明。

## 分发限制

此包只有 ad-hoc 签名，没有 Apple Developer ID 和公证。没有关闭 Gatekeeper 或清除下载隔离标记；本地构建的启动成功不能证明互联网下载后不需要系统授权。实际最低系统未逐一测试，其他架构无安装包。Docling/OCR 未捆绑。
