# 问答、等待与阅读附件

输入框旁可选择已配置的模型和实际支持的思考档位，只影响当前会话。新增会话继承全局配置，旧会话恢复保存选择；服务已移除时恢复当前可用服务。未知型号仅提供服务默认。生成过程中不能变更本轮配置。

「生成 HTML」开关让本轮回答附带独立文件，支持隔离交互、全屏和下载。Markdown 正文与 HTML 文件分别持久化，HTML 源码不进入后续模型历史。模型未输出可用文件时使用基础阅读版；停止、截断或故障时保留已有内容并标记未完成。

等待区提供阶段和经过时间，完成后可展开查看检索、上下文整理、压缩及引用校验的记录。流式正文定期保存；刷新页面不停止服务端生成，重新打开会话可接续进度。服务中断后保留已经保存的正文，尚未落库的增量不能恢复。

阅读文件使用无同源权限的 sandbox iframe，CSP 限制网络、外部资源、表单与导航。安全预览版本与原始下载独立；全屏支持 Escape、焦点约束和关闭后焦点恢复。会话进入回收站后附件不再可访问，永久删除会话时附件随消息删除。

本地准备、压缩、模型请求、首段正文与保存完成分别记录时间和用量，不保存推理正文或凭据。模型等待不能等同于本地计算耗时，HTML 输出长度也会影响等待；不根据单次样本自动降低用户档位。

测试覆盖配置恢复、引用、流式边界、取消和网络失败、附件访问与删除、手机布局、全屏与下载。复现使用 `pnpm build`、`pnpm typecheck`、`pnpm test` 和 `pnpm test:e2e`；当前数量与边界见 [v0.2.2 验收](release-validation-2026-10-03.md)。
