# 问答、等待与阅读附件

输入框旁可选择已配置的模型和实际支持的思考档位，只影响当前会话。新增会话继承全局配置，旧会话恢复保存选择；服务已移除时恢复当前可用服务。未知型号仅提供服务默认。生成过程中不能变更本轮配置。

「生成交互阅读页」开关先返回普通文字回答，再启动独立的页面任务。文字完成后可以继续提问；页面支持停止、重新生成、隔离交互、全屏和下载。页面失败或停止时，已经完成的文字回答保留。Markdown 正文与 HTML 文件分别保存，HTML 源码不进入后续模型历史。

页面任务使用 `lib/chat/html-guidance.ts` 的生成指令，沿用已完成的回答、它引用的资料和本轮模型配置，不再检索知识库。任务通过现有任务队列保存状态；刷新页面可以继续查看，应用重启造成的中断可以手动重新生成。页面完整性与引用通过检查后才开放预览和下载。指令要求按问题选择流程图、关系图、并列比较或有资料依据的参数演示；结论和概览默认可读，引用文字预先写入正文，再由脚本切换状态。动画用于解释变化，步骤可前进、返回与重置；需要播放时由用户启动并可暂停、重播。

新附件与基础阅读版共用 `lib/documents/reading-style.ts` 的暖白、近黑、细边框、系统中文字体和明暗主题。共用样式排在内容样式之前，让图形可以自行适配布局；主体提供 `weave-reading` 容器，图形按实际阅读宽度切换。预览和全屏通过受限窗口消息跟随项目主题，切换主题不重新加载附件；下载文件跟随系统。历史附件保留原配色，导入的 HTML 原件不加入这套样式。

等待区提供阶段和经过时间，完成后可展开查看检索、上下文整理、压缩及引用校验的记录。流式正文定期保存；刷新页面不停止服务端生成，重新打开会话可接续进度。服务中断后保留已经保存的正文，尚未落库的增量不能恢复。

阅读文件使用无同源权限的 sandbox iframe，CSP 限制网络、外部资源、表单与导航。安全预览版本与原始下载独立；全屏支持 Escape、焦点约束和关闭后焦点恢复。会话进入回收站后附件不再可访问，永久删除会话时附件随消息删除。

本地准备、压缩、模型请求、首段正文与保存完成分别记录时间和用量，不保存推理正文或凭据。模型等待不能等同于本地计算耗时，HTML 输出长度也会影响等待；不根据单次样本自动降低用户档位。

文字先返回的真实验收使用 `pnpm exec tsx scripts/verify-chat-artifact.mts http://127.0.0.1:3001 <证据目录>`。服务必须使用系统临时目录内的真实知识库副本；脚本会请求真实模型，检查继续提问、页面停止、真实连接失败、重新生成和浏览器操作。生成页必须完成后才开放预览和下载。

测试覆盖配置恢复、引用、流式边界、取消和网络失败、附件访问与删除、手机布局、全屏与下载。复现使用 `pnpm build`、`pnpm typecheck`、`pnpm test` 和 `pnpm test:e2e`；当前数量与边界见 [v0.2.3 验收](release-validation-2026-10-05.md)。

真实生成验收使用 `pnpm exec tsx scripts/verify-reading-pages.mts --generate`，只读取当前模型配置，在临时知识库生成流程、图形比较、参数变化三个页面，默认保存到 `docs/evidence/reading-pages`。`pnpm exec playwright test -c playwright.reading.config.ts` 默认检查本次存档的 `docs/evidence/reading-pages-2026-10-03` 样本与项目预览；控件行为断言对应这些实际文件。新增生成样本需按实际控件补充行为断言，可通过 `WEAVE_READING_EVIDENCE_DIR` 指定目录。浏览器验收使用独立临时知识库与端口 3350，结束后清理服务和数据库。真实样本证明这些具体页面的行为，不代表所有模型和知识主题的生成质量。
