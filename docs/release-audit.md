# 首版代码与公开范围审计

本文保留 v0.1.0 的历史审计口径；当前桌面安装与真实评测结果见 [v0.2.0 验收](desktop-validation.md) 和 [指标说明](evaluation/2026-10-02/metrics.md)。

本轮面向公开代码交付：排除个人资料和配置，证明新使用者可以独立安装运行，并处理影响维护或失败恢复的问题。采用局部修改，沿用现有模块与数据模型。可执行验收结果见 [validation.md](validation.md)。

## 已处理事项

| 范围 | 发现与处理 |
| --- | --- |
| 发布边界 | 使用显式文件清单创建独立首版仓库，不复制开发仓库历史；忽略环境文件、数据库、知识库、内部审计、代理工作树和生成产物 |
| 安装与依赖 | 固定 Node/pnpm、提交锁文件与全部迁移；移除无调用的模型 SDK 和构建插件，补齐文档命令所需的 tsx；去掉缺少依赖的测试 UI 命令 |
| 依赖安全 | Drizzle 开发工具链带入旧 esbuild；通过限定父依赖的 override 使用修复版本，验证生成工具可运行且无新增 schema 差异；首版验收时依赖安全检查为零已知漏洞 |
| 类型与风格 | 加入 Next ESLint 规则、零警告门槛和 TypeScript 未使用声明检查；清理无用导入和变量，保留公开函数的参数位置及原有副作用 |
| React 与请求 | 修正引用在渲染期写入、回调依赖和过期请求取消；对无法直接套用的少数规则保留带解释的局部例外 |
| 模型探测 | 可用性检查复用统一模型列表适配器；补测原生 Claude 鉴权、列表不支持与型号缺失，不回显凭据或上游正文 |
| 写入恢复 | 去除重复回滚；某个文件恢复失败仍尝试其余文件和 Git 暂存恢复，保留原始原因及全部恢复失败；增加故障注入回归 |
| 数据边界 | 删除无调用的全库清空辅助函数，纠正“数据库只是缓存”的过时注释；明确索引重建保留应用记录、备份必须覆盖完整知识库 |
| 文档与示例 | 精简重复审计和过时流程；补充架构、恢复边界、支持范围和贡献检查；移除真实服务配置与内部报告链接，删除模板 SVG 和重复探测脚本 |
| CI | macOS/Linux 安装、lint、构建、类型、测试与浏览器回归；独立密钥扫描任务拉取完整历史，使用固定版本与官方 SHA-256 校验的 Gitleaks CLI |

`lib/settings.ts` 的供应商地址模板属于公开产品默认值；其中 OpenCode 地址已依据 [官方文档](https://opencode.ai/docs/go/)核实。作者的服务选择、密钥、请求头值和位置记录均不进入交付。Gitleaks 未使用忽略测试或自定义扫描例外。

## 仍需持续维护的部分

- 聊天工作区、导入抽屉和导入流水线仍是大型模块。它们已有职责分区和回归覆盖，但后续功能变更应逐步抽取稳定边界，不宣称已完成全面拆分。
- 当前 Next 的 React ESLint 插件尚不支持 ESLint 10；首版采用兼容的 ESLint 9，该工具线已标记弃用。Drizzle 也带入弃用的旧加载器。首版依赖审计结果不代表后续版本已解除维护风险，需跟随上游更新。
- 网络请求、草稿恢复和本机偏好同步保留 effect；`set-state-in-effect` 规则未启用，其余 Hooks 检查仍启用。零警告是已执行的工程门槛，不是代码完美的证明。
- 后续修复加入 fsync、持久化事务日志与启动恢复，Git 备份也移到业务提交之后。文件和 SQLite 仍不构成硬件层面的统一事务；恢复遇到外部编辑或再次失败时需停止服务，核对完整备份。详见[后续修复验收](hardening-validation.md)。
- 首版无认证、只供本机单用户运行；macOS / Linux CI 已通过，正式支持范围仍为 macOS。真实模型质量、OCR 安装、Windows 和多人并发未在本轮验收。

审核依据是当时的代码、安装结果和回归证据；当前发布结果见 [v0.2.1 验收](release-validation-2026-10-03.md)。
