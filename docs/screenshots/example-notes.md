# 截图使用的手写示例资料

以下资料用于准备截图中的 10 个词条。内容仅为演示笔记，不作为学习方法的科学评测依据。

# 学习方法

把阅读、整理和复习连接成一个可持续的过程。

## 学习流程

先用 [[阅读笔记]] 记录问题和来源，再把重复出现的想法整理成 [[知识整理]] 中的概念。

用 [[主动回忆]] 检查理解，按照 [[间隔复习]] 安排回顾。每周用 [[学习回顾]] 决定下一步。

# 知识整理

把资料中的共同概念连接起来，保留可追溯的来源。

## 整理方式

每个词条围绕一个清楚的问题。记录自己的理解，并保存 [[来源记录]]，方便以后回到原文核对。

用 [[概念关联]] 连接同一主题的词条，避免只积累互不相连的文件。

# 主动回忆

合上资料，用自己的话回答问题，检查理解。

## 如何使用

读完一段内容后，暂时离开原文，试着回答：这段内容解决什么问题？它与以前学过的内容有什么联系？

把回答不了的问题保存到 [[复习问题]]，再回到 [[阅读笔记]] 核对。可以结合 [[间隔复习]] 安排下次回顾。

# 间隔复习

把同一主题的回顾分散安排，并根据掌握情况调整。

## 复习安排

不要把所有回顾集中在同一天。重新回答 [[复习问题]]，已经熟悉的内容稍后再复习，仍然模糊的内容提前处理。

复习时配合 [[主动回忆]]，把发现的问题加入 [[学习清单]]。

# 概念关联

记录概念之间的关系，以及建立联系的理由。

## 建立联系

把 [[阅读笔记]] 中重复出现的概念整理为词条。用双链连接相关内容，并写出为什么相关。

联系可以帮助回到原文，但不能代替 [[来源记录]] 和核对。

# 来源记录

保留原始资料和引用片段，便于核对。

## 记录来源

区分原文、模型建议与自己的判断。保存标题和支持结论的片段，修改 [[知识整理]] 时可以返回原文。

来源更新后，把需要重新判断的问题加入 [[学习回顾]]。

# 阅读笔记

记录自己的问题、理解和待核查的内容。

## 阅读时记录什么

记下核心问题、关键概念和自己的理解。需要后续核对的内容连接到 [[来源记录]]。

适合长期使用的概念放入 [[知识整理]]，暂时不清楚的内容进入 [[复习问题]]。

# 复习问题

把模糊的理解转成下一次能回答的问题。

## 本周问题

- [[主动回忆]] 与反复阅读有什么操作上的差别？
- 如何把 [[间隔复习]] 加入自己的日常安排？
- 哪些 [[概念关联]] 还缺少明确理由？

# 学习回顾

检查资料、词条和问题的变化，决定下一步。

## 每周回顾

检查 [[学习清单]]：哪些问题已经解决？哪些内容还需要核对？

回到 [[学习方法]]，选择下一次阅读和复习的重点。

# 学习清单

保存下一步动作，让学习安排可以继续执行。

## 下一步

- 整理新的 [[阅读笔记]]。
- 为重要概念补充 [[来源记录]]。
- 回答一个 [[复习问题]]。
- 完成一次 [[学习回顾]]。

# 本次实际导入的文字：阅读后的问题清单

读完一份资料，我先用自己的话总结，再记录自己无法解释的地方。每个问题保存相关原文和自己的理解。

问题分成三个部分：已经理解、还需要核对、以后再学。下次阅读时先检查“还需要核对”的问题；找到新证据后更新记录。每周回顾时删除已经解决的待办，保留问题和答案供以后查看。

这份清单与阅读笔记、复习问题和学习回顾一起使用。问题清单负责保存待解决的问题，学习清单负责安排下一步动作。
