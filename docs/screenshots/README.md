# 界面截图说明

## 当前版本：v0.2.2

以下五张截图于 2026-10-03 从公开发布的 v0.2.2 DMG 复制安装后拍摄，使用亮色主题与独立示例知识库。[拍摄版本、尺寸与文件指纹](capture-v0.2.2.json)记录对应安装包 SHA-256 和源码标签；[下载及安装验收](../release-validation-2026-10-03.md)。

| 文件 | 展示 |
| --- | --- |
| [knowledge.png](knowledge.png) | 当前知识库目录、搜索、类型筛选和导入入口 |
| [chat.png](chat.png) | 真实模型回答、已校验引用与归档入口 |

知识库、问答、审阅和图谱画面由该安装包内置服务提供，在浏览器中拍摄；原生截图保留实际应用窗口。图谱通过界面的“复位视图”调整缩放。未拼接画面或修改页面元素，统一为 PNG 无损编码，并核对编码前后的解码像素一致。

示例知识库预先准备了 10 个手写学习方法词条和 29 条双链，[示例资料](example-notes.md)公开保留。问答与导入草稿通过真实 `deepseek-v4.1-flash` 服务生成，使用应用的实际流程和引用检查；没有模拟响应。个人资料、位置配置、账号标识和密钥不进入截图。

这些画面展示当前流程的一次实际使用。正式质量指标仍对应 v0.2.0 的冻结评测；本次截图没有增加评测样本，也没有验证普通用户的首次使用成功率。

复现时可用示例资料在独立知识库准备词条，配置自己的模型，依次浏览知识库、提问、导入“阅读后的问题清单”并展开草稿，再查看关系网络。模型输出与图谱位置可能变化；不要截取含个人知识或服务凭据的设置页面。
