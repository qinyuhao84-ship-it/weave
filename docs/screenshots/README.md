# 界面截图说明

这组截图来自织识首版真实生产界面，日期为 2026-10-01；使用 macOS Chrome 的独立无界面进程、1440 × 1000 视口和亮色主题。未拼接或修改页面元素；图谱截图通过界面的“复位视图”调整缩放。

| 文件 | 展示 |
| --- | --- |
| [knowledge.png](knowledge.png) | 词条目录、类型筛选与双链统计 |
| [chat.png](chat.png) | 引用问答、关联词条与归档入口 |
| [review.png](review.png) | 资料导入后的词条草稿、原文证据和写入确认 |
| [graph.png](graph.png) | 知识节点与双链关系 |

使用临时知识库中的推荐系统合成学习笔记，不包含作者的知识正文、路径、身份信息或模型密钥。问答与导入建议由本地模拟模型返回，只用于展示流程，不证明真实模型回答质量；截图中的 `weave-demo` 是演示标识。

复现相同操作可用自己的非敏感示例资料，启动应用后依次浏览知识库、图谱、提问和导入审阅。不要截取包含个人知识、位置配置或服务凭据的设置页面并提交。
