# 界面韧性专项复核（2026-10-03）

本记录补充 2026-10-02 已确认的视觉方向和 31 条界面调整，范围限于读取失败、加载中、路径切换及窄屏边界。暖纸、近黑与编织标识保持原样，不重复记录既有视觉修改。

## 本轮结果

- 知识库摘要在首次响应前显示未知／加载状态；失败时显示失败提示和原位重试，不再以绿色健康状态或零词条冒充成功。
- 共用 `useApi` 取消过期请求。错误记录绑定发起请求时的 path；渲染时只暴露当前 path 的错误，切换路径后旧错误立即隐藏。同 path 重试期间保留原错误，成功后清除。
- 原始资料详情将解析正文和来源 ID 关联；切换来源时取消旧请求，读取失败显示原位恢复动作，避免把上一份资料的正文展示在当前来源下。
- 图谱已有数据时刷新失败会保留图谱，同时显示错误和重试入口。
- 聊天输入对 `keyCode 229` 和组合输入事件不提交；普通 Enter 发送失败时保留输入内容。
- 词条、来源、回收站和设置等读取失败显示错误和重试；首次读取显示稳定的加载骨架。窄屏搜索对不含空格的长标题允许换行；全文命中标题最多显示三行，完整标题保留在原生 `title` 提示中，避免单张结果卡片被长标题撑高。常用开关和来源下载操作保留 44px 触控高度。

## 验证记录

- UI 韧性 Playwright 定向用例：11 项通过，用时 39.9 秒；使用隔离临时知识库与模拟响应。
- 自动 Axe 检查仅覆盖知识库首次读取失败态和 320px 长标题搜索态。它不等同于完整人工读屏、键盘、放大和无障碍认证。
- 四张 320px 截图覆盖暗色错误、加载骨架、长标题搜索与模型开关；输出在隔离验收副本的 `test-results/`，仅作为验收产物。
- 最终版本已完成 lint、生产构建、typecheck、53 个单测文件／813 项测试及 37 项完整 E2E；完整 E2E 用时约 1.6 分钟，包含最终的路径绑定错误与搜索恢复修改。
- 全文命中存在时不再同时展示“没有匹配词条”，仍等待正文检索时也不提前宣称无结果。长标题最多三行；完整文本保留在可访问名称与标题提示中。

截图只说明自动化捕获时的布局和状态；320px 视口检查不能替代真实设备触控、输入法与读屏验收。模拟接口只证明 UI 恢复链路，不证明真实模型回答质量。
