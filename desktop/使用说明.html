WEAVE · 本地知识工作台

让知识留在自己的电脑里。

将「织识」拖入「Applications」，弹出磁盘映像，再从应用程序打开。应用内置 Node 与本地 Git，无需启动终端。

第一次使用

  1. 默认知识库在 ~/Documents/织识。已有同名目录会保留并读取原资料。
  2. 打开「设置」（⌘ ,）填写自己的模型服务与型号。没有模型时仍可浏览、编辑和全文搜索。
  3. 导入资料后先审阅草稿，再确认写入；问答引用可打开原文核对。
预览包使用 ad-hoc 签名，尚未 Apple 公证。网络下载后 macOS 可能要求在「隐私与安全性」中授权；请先核对下载来源与 SHA-256。不要关闭 Gatekeeper。

保存、升级与备份

Markdown 是内容真源；隐藏的 .weave 还保存会话、任务、原件与设置。升级前使用 ⌘ Q 退出，再复制整个知识库（包括 .weave 与 .git）。仅复制 Markdown 不能恢复完整应用。

安装到任意独立目录都可以使用。升级时替换应用；卸载只需移走应用，不会自动删除知识库。恢复时先退出应用，恢复完整备份，再在设置中选择知识库位置。

遇到问题

「帮助 → 打开诊断日志」可打开应用支持目录。应用保留最近三份有大小上限的桌面日志；启动失败可重试打开。不要通过删除 SQLite 修复索引。

支持 Apple Silicon，最低构建系统 macOS 13.5。内置基础 Markdown、文本、HTML、DOCX、数字 PDF 解析；OCR、扫描 PDF 与 PPTX 需另行配置解析服务。
